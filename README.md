# Task Manager

Веб-приложение на Django для управления задачами с авторизацией пользователей.

## Возможности

- Регистрация и вход пользователей
- Создание, редактирование, удаление задач
- Приоритеты задач (низкий, обычный, высокий)
- Сроки выполнения с визуальной подсветкой просроченных
- Отметка выполнения задач
- Разграничение доступа (каждый пользователь видит только свои задачи)

## Технологии

- Python 3.10+
- Django 6.1
- Bootstrap 4
- SQLite (по умолчанию)
